# Heart Disease Prediction App ❤️

This is a Machine Learning web application built using Streamlit and Logistic Regression.

## Features
- Predicts likelihood of heart disease
- Interactive user interface
- Probability score display

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- NumPy
- Joblib

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
